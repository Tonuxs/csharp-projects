# TGPSI C# Projects

A collection of C# exercises and projects developed during the TGPSI (Technician in Management and Programming of Information Systems) course at Agrupamento de Escolas da Batalha.

## 📖 About

This repository showcases the C# applications and exercises I developed throughout my second year of the TGPSI course. These projects helped me strengthen my understanding of object-oriented programming and desktop application development using the .NET ecosystem.

## 🎯 Objectives

* Practice object-oriented programming concepts
* Develop problem-solving skills
* Learn to build desktop applications
* Improve code organization and debugging techniques
* Gain experience with the .NET platform

## 🛠️ Topics Covered

* Variables and data types
* Classes and objects
* Encapsulation
* Inheritance and polymorphism
* Exception handling
* Collections
* Event-driven programming
* Windows Forms development
* File handling
* Basic database integration

## 📂 Repository Structure

Each folder contains exercises or projects related to specific topics studied during the course.

```text
Project/
├── Project.sln
├── Project.csproj
├── Program.cs
└── ...
```

## 🚀 How to Run

1. Clone the repository.
2. Open the solution (`.sln`) file using Visual Studio.
3. Build and run the project.

```bash
git clone https://github.com/Tonuxs/tgpsi-csharp-projects.git
```
